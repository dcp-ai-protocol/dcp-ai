# 公開済み Rust crate

> [英語原文](RUST_RELEASE.md)の参考訳。26/10/2026 更新。識別子とコード例は原文のままです。

26/10/2026 確認：[`dcp-ai` 2.11.0](https://crates.io/crates/dcp-ai/2.11.0) は crates.io で公開済みです。crate のバージョンは DCP のワイヤー形式・仕様バージョンとは独立しています。今回の公開は Rust のみです。npm、Python、Go、コンテナーは個別のリリースです。

<a id="install"></a>

## インストール

現在の安定版 Rust ツールチェーンを使い、アプリケーションの crate から実行します。変更後の `Cargo.toml` と `Cargo.lock` をコミットしてください。この例は互換性のある 2.x 更新を許可します。完全固定が必要なら manifest で `=2.11.0` を指定します。

```bash
cargo add dcp-ai@2.11.0
cargo check --locked
```

```toml
[dependencies]
dcp-ai = "2.11.0"
```

任意の OTLP エクスポートと WebAssembly バインディングは `otlp` と `wasm` で選択します。対象に必要な機能だけを有効にしてください。この Rust リリースで別の npm WASM パッケージは再公開しません。

<a id="upgrade-and-compatibility"></a>

## 更新と互換性

V2 の責任主体・鍵・成果物・チェックポイント検証の修正、明示的な信頼と `strict-v1`、委任チェーン、V2 バンドル構築・署名、実験的候補 API を含みます。10 フィールドの `V2VerificationResult` API の互換性は維持され、署名者の詳細は別に取得できます。テレメトリは `2.11.0` を報告します。[SDK README](../sdks/rust/README.md)、[受け入れガイド](ADMISSION.md)、[セキュリティ方針](../SECURITY.md)を参照してください。

検証は 2.10.0 より厳密です。以前受理された不正・不整合な証拠が拒否される場合があります。過去の証拠は書き換えず保存してください。`dcp-jcs-v1` は規範かつデフォルトのままです。`dcp-jcs-v2` は実験的・非規範で明示的な選択が必要です。検証は責任主体への信頼、受け入れ、権限を与えません。Rust には A2A AES-256-GCM セッション暗号化とリプレイウィンドウがまだなく、V2 ビルダーは PQ チェックポイントを生成しません。検証器は主監査チェーンを確認しますが、任意の副 SHA3-256 チェーン・ルートは再計算しません。

<a id="validation"></a>

## 検証

既定スイートは 261 件、全機能スイートは 267 件に合格しました（doctest を含む）。WASM ライブラリとテストは `wasm32-unknown-unknown` 向けにコンパイル済みですが、これはブラウザー実行テストではありません。Cargo による 71 ファイルのパッケージ化・検証と公開 dry-run に合格しました。展開した crate に対する外部利用側の 72 件（受け入れ、互換性、候補入力・ルーター、検証器の回帰テスト）が合格し、反転した負の対照は期待どおり失敗しました。公開後、新規レジストリキャッシュからローカルパスや patch なしで正確に 2.11.0 を解決し、同じ 72 件に合格しました。公開アーカイブの checksum とソースのバイト列はレビュー済みリリースと一致しました。テスト用共有 fixture はリポジトリから取得します。アプリケーションには不要です。
