# 公開済み Go モジュール

> [英語版](../../../docs/GO_RELEASE.md)の参考訳。09/11/2026 更新。相違がある場合は英語版が優先されます。

05/11/2026 確認：Go SDK `v2.13.0` は[タグ `sdks/go/v2.13.0`](https://github.com/dcp-ai-protocol/dcp-ai/tree/sdks/go/v2.13.0/sdks/go)で公開済みで、公開モジュール proxy と checksum データベースから提供されています（[変更点](#what-changed-in-v2130)）。以前のリリース `v2.11.1`（[`sdks/go/v2.11.1`](https://github.com/dcp-ai-protocol/dcp-ai/tree/sdks/go/v2.11.1/sdks/go)、28/10/2026 確認）と `v2.11.0`（[`sdks/go/v2.11.0`](https://github.com/dcp-ai-protocol/dcp-ai/tree/sdks/go/v2.11.0/sdks/go)、26/10/2026 確認）の記述は以下に残しています。モジュールとインポートパスは `/v2` を維持します。SDK バージョンは DCP のワイヤー形式・仕様バージョンと独立しています。別のレジストリトークンは不要で、利用側は Go モジュールシステムでリポジトリのタグを解決します。

<a id="install"></a>

## インストール

Go 1.25 以降が必要です。アプリケーションのモジュールで実行し、その `go.mod` と `go.sum` を更新して保存してください。

```bash
go get github.com/dcp-ai-protocol/dcp-ai/sdks/go/v2@v2.13.0
go mod verify
```

<a id="what-changed-in-v2111"></a>

## v2.11.1 の変更点

[VERIFICATION.md の V2-11](../../../spec/VERIFICATION.md#step-v2-11-verify-dual-hash-audit-chain-if-present) の二次の SHA3-256 フィールドが存在する場合、それらを検証します：`audit_merkle_root_secondary`（一次と同じ方法で作る SHA3-256 の木。空の記録では `sha3-256:` に 64 個のゼロを続けた値）、各 `prev_hash_secondary`（最初のエントリーでは `"GENESIS"`、以降はバンドルに含まれているとおりの直前のエントリーの SHA3-256）、各 `intent_hash_secondary`（インテントのペイロードの SHA3-256）。存在しないフィールドは要求されないため、検証済みのバンドルが完全な二次チェーンを持たないこともあります。存在するフィールドが `null`、文字列でない、または不整合の場合は拒否されます。これは、これらのフィールドを持つ証拠について、v2.11.0 が受け入れていたものに対する受け入れの変更です。API、結果のフィールド、`dcp-jcs-v1`、実験的でオプトインの `dcp-jcs-v2` API、`hash_alg` の扱いは変わりません。検証は引き続き、プリンシパルへの信頼、受け入れ、認可ではありません。 SDK のテレメトリーは `2.11.1` を報告します。

<a id="upgrade-and-compatibility"></a>

## 更新と互換性

v2.11.0（2026 年 10 月 26 日）に含まれ、v2.11.1 も引き継ぐもの：V1 の不正な鍵長に対するエラー処理、V2 の責任主体・鍵・成果物・チェックポイント検証の修正、責任主体への明示的信頼と `strict-v1`、委任チェーン、リプレイ保護付き並行 A2A セッションを含みます。v2.11.0 では SDK テレメトリーは `2.11.0` を報告していました。[SDK README](../../../sdks/go/README.md)、[受け入れガイド](../../../docs/ADMISSION.md)、[セキュリティポリシー](../../../SECURITY.md) を参照してください。

v2.10.0 より検証が厳密で、以前受け入れられた不正形式や不整合の証拠を拒否する場合があります。過去の証拠は書き換えず保存してください。`dcp-jcs-v1` は規範的な既定値で、`dcp-jcs-v2` API は実験的・非規範的かつ明示的なオプトインです。検証は責任主体への信頼、受け入れ、認可とは異なります。v2.11.0 では任意の副次 SHA3-256 フィールドは検証器の検査対象外でした。v2.11.1 は存在する場合にそれらを確認します。

<a id="validation"></a>

## 検証

v2.13.0 では、公開 proxy がタグ `sdks/go/v2.13.0`（コミット `46b142bd`）に対して提供するモジュールは、公開前にテストしたモジュールと同じ 92 ファイルを含み、checksum データベースはテスト済みモジュールのハッシュ `h1:bRkqSUWHQ/qTywPmKWRdzg2bBWI0RG1ZZAlb6IafnyU=` を記録しています。checksum データベースを有効にし、ローカルの `replace` なしで `proxy.golang.org` から v2.13.0 を解決した利用側は、外部適合性キット（7 カタログ、697 ケース）、v2.13.0 で変わる API の確認、デフォルトプロファイルの確認に合格しました。

v2.11.1 では、proxy が提供するモジュール zip の 84 ファイルが `main` と同一で（Go は zip にリポジトリのルートの `LICENSE` を追加します）、proxy と checksum データベースがこのバージョンを確認しました。ローカルの `replace` なしで proxy から `v2.11.1` を解決する外部利用側は 189 件のテストに合格しました。

v2.11.0（2026 年 10 月 26 日）では、既定スイートと `-race -tags otlp` スイートは各 1,154 件のテスト・サブテストに合格しました。1 件は独立した producer/consumer 相互運用テスト用に意図的に留保されています。`go mod tidy -diff`、ビルド、vet に合格しました。外部利用側の 137 件が合格し、負の対照は期待どおり失敗しました。公開モジュールを公開 proxy と checksum 検証で新しいキャッシュに取得し、ソースがレビュー済みコミットと一致しました。その後ローカル `replace` 指定なしで外部利用側が合格しました。Rust の個別公開は [Rust](../../../docs/RUST_RELEASE.md) を参照してください。

<a id="what-changed-in-v2130"></a>

## v2.13.0 の変更点

v2.13.0 は 05/11/2026 に `main`（`46b142bd`）上のタグ `sdks/go/v2.13.0` で公開されました。下記の v2.12.0 を置き換えます。v2.12.0 はタグ付けされませんでした。v2.11.1 と比べて、v2.13.0 は次のとおりです：

- **V2-2 のスキーマ検証を実行します（受け入れの変更）。** `v2.VerifySignedBundleV2` とその変種は、ハッシュ、鍵、署名を確認する前に、署名済みバンドルのエンベロープと 4 つのペイロードを `schemas/v2` に照らして検証します。以前は受け入れられていたスキーマ上無効なバンドルは、`schema: <pointer> <keyword>` 診断で失敗するようになりました。
- **`v2.VerifyPayloadHash` を修正します（受け入れの変更）。** 下記の v2.12.0 と同じく、`SignPayload` が書き込むとおり `"sha256:"` の後に正規ペイロードの SHA-256 が続く場合にだけ `true` で、接頭辞のないダイジェストは `false` です。
- **`v2.RawAuditEventV2` を追加します。** 下記の v2.12.0 と同じです。
- **委任状の確認を揃えます。** `v2.VerifyMandateValidity` は一つの契約を適用し、`v2.VerifyMandateValidityAt`（新規）は検証時刻を受け取ります。以前は受け入れられていた欠落した日付や不正な形式の日付は無効です。`v2.VerifyMandateChain` はすべての時刻を同じ方法で読み取り、ドメインを繰り返すルート委任状を拒否します。

`SDKVersion` は `2.13.0` です。ワイヤーフォーマット、署名、プロファイル、規範的なデフォルトとしての `dcp-jcs-v1`、実験的なオプトイン `dcp-jcs-v2` API は変わりません。過去の証拠は書き換えずに保持してください。新しい確認で拒否されるバンドルも、受け取ったままにします。公開済みのモジュールに含まれる SDK README は公開前に準備したもので、「prepared, not published」と記載しており、`v2.VerifyPayloadHash` の行と `v2.RawAuditEventV2` の段落はまだ「prepared for v2.12.0」と記載しています。公開済みのモジュールは変更できません。リポジトリの README が v2.13.0 を説明します。[SDK README](../../../sdks/go/README.md)と[変更履歴](../../../CHANGELOG.md#unreleased)を参照してください。

<a id="prepared-not-published-v2120"></a>

## 準備済み・未公開: v2.12.0

v2.12.0 は 30/10/2026 にリポジトリで準備済みですが、公開されていません。`sdks/go/v2.12.0` タグが存在しないため、モジュールプロキシはこのバージョンを配信せず、`go get` でも解決できません。準備の時点では、インストールコマンドは v2.11.1 のままでした。現在のコマンドは上記のとおり v2.13.0 を指定しています。v2.11.1 と比べて、v2.12.0 は次のとおりです。

- **`v2.VerifyPayloadHash` を修正（受け入れの変更）。** `payload_hash` が `"sha256:"` の後に `dcp-jcs-v1` 正規ペイロードの SHA-256（小文字の 16 進）を続けた値と完全に一致する場合にだけ `true` を返します。`v2.SignPayload` の出力は受け入れられるようになり、接頭辞のないダイジェストは拒否されるようになりました。v2.11.1 はその逆でした。この関数が確認するのはハッシュの整合性だけで、署名、鍵、ポリシー、プリンシパルへの信頼、受け入れは確認しません。バンドル検証はこの関数を使用したことがなく、変わりません。
- **`v2.RawAuditEventV2` を追加。** 受信した監査エントリーのバイト列をそのまま保持するため、明示的な `null` と未知のメンバーは転送後も残ります。`Typed()` は情報が失われるビューです。`AuditEventV2` などの型付き構造体は生成用の型のままで、動作は変わりません。

その他の API、バンドル検証、`dcp-jcs-v1`、実験的でオプトインの `dcp-jcs-v2` API は変わりません。実験的候補の新しいテストはどのデフォルトも変更しません。SDK のテレメトリーは `2.12.0` を報告します。モジュールには翻訳版 README が含まれなくなりました。これらは現在、リポジトリの `i18n/` ツリーにあります。[SDK README](../../../sdks/go/README.md) と[変更履歴](../../../CHANGELOG.md)を参照してください。

> **注記（05/11/2026）。** 上の比較は、準備済みの v2.12.0 について 30/10/2026 に書いたもので、v2.12.0 はまだ公開されていません。その後 `main` は検証を変更しました。すべての V2 検証器が V2-2 のスキーマ検証を実行し（#116、02/11/2026）、委任状の有効性ヘルパー、チェーンの時刻確認、繰り返されるルートドメインの確認が変わりました（#117〜#119）。これらの変更は上記の v2.12.0 には含まれません。v2.12.0 はタグ付けされず、上の v2.13.0 がこれらの変更を含んで置き換えており、`main` のマニフェストは v2.13.0 を記載しています。[監査資料](../../../docs/conformance/AUDIT_DOSSIER.md#artifacts)を参照してください。

<a id="prepared-not-published-v2140"></a>

## 準備済み・未公開：v2.14.0

08/11/2026 に準備し、公開していません。`sdks/go/v2.14.0` タグはまだなく、上記のインストールコマンドは、タグが公開されてモジュールプロキシが確認されるまで v2.13.0 のままです。

- **追加（オプトイン）。** `v2.AdmitDelegatedBundleV2`、`v2.AdmitSignedBundleV2FromBytes`、`v2.CreateMandateAcknowledgment`、`v2.EvaluateDelegationActivationV2`（[変更履歴](../../../CHANGELOG.md#unreleased)）。
- **受理の変更。** V1 オブジェクトの検証とデフォルトの V2 Ed25519 プロバイダーにおける P-ED-1。
- **修正。** SLH-DSA-192f のプロバイダーは鍵をパニックなしで読み込みます。`SDKVersion` は `2.14.0` です。
